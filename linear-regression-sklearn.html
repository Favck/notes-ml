Постановка задачи

1. Идея и данные

Scikit-learn — библиотека машинного обучения с единым интерфейсом для моделей. В частности, она предоставляет API в стиле Estimator: модель создаётся как объект, обучается методом .fit(), а предсказания строит методом .predict().

В примере рассматриваются рекламные расходы и продажи продукта. Нужно выяснить, как расходы на рекламу по разным каналам связаны с продажами, а затем научиться предсказывать продажи.

ОбозначениеСодержаниеРоль
TVБюджет рекламы на телевиденииПризнаки X
radioБюджет рекламы на радио
newspaperБюджет рекламы в газетах
salesОбъём продажЦелевая переменная y

В исходном датасете расходы измеряются в тысячах долларов, а продажи — в тысячах единиц товара.

Что здесь называется линейной регрессией? Модель ищет коэффициенты в формуле ŷ = b₀ + b₁·TV + b₂·radio + b₃·newspaper. Она линейна по коэффициентам. В простейшем случае с одним признаком это прямая; здесь же три признака, и модель описывает гиперплоскость.

Каждая строка таблицы — одна рекламная кампания, её три бюджета — признаки X, реальные продажи — ответ y. Предсказание обозначаем ŷ (y с крышечкой).

Важная идея: качество модели нужно проверять на данных, которые она не использовала при обучении. Иначе мы не получим честную оценку того, как модель будет работать на новых наблюдениях.

Обозначения: X — матрица признаков; y — правильные ответы. После разбиения получаем X_train, X_test, y_train и y_test.
Подготовка данных

3. Разделение на обучающую и тестовую выборки

Для разделения используется train_test_split из sklearn.model_selection.

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.3,
    random_state=42
)
70% · Train
Модель обучается
30% · Test
Модель оценивается
  • test_size=0.3 — 30% данных отправляется в тестовую выборку, оставшиеся 70% — в обучающую.
  • random_state — фиксирует случайное разбиение, чтобы при повторном запуске получить тот же результат.
Не обучаем модель на тестовой выборке. Иначе тест перестанет быть независимой проверкой на ранее не виденных данных.

Подготовка X и y

df = pd.read_csv("Advertising.csv")

X = df.drop("sales", axis=1)
y = df["sales"]

Здесь sales исключается из таблицы признаков и становится целевой переменной.

Проверка формы данных
print(X.shape)       # (число объектов, 3)
print(y.shape)       # (число объектов,)
print(X_train.shape, X_test.shape)

Если CSV содержит служебную колонку Unnamed: 0 с номерами строк, её нужно исключить из X: это не рекламный бюджет.

Обучение

4. Создание и обучение модели — Estimator API

В Scikit-learn модель — это объект класса. Для линейной регрессии используется LinearRegression.

  1. Импортируем класс модели
    from sklearn.linear_model import LinearRegression
  2. Создаём экземпляр
    model = LinearRegression()
  3. Обучаем на тренировочных данных
    model.fit(X_train, y_train)
  4. Получаем предсказания для тестовых объектов
    pred = model.predict(X_test)
Оценка качества

5. Метрики регрессии

После получения предсказаний сравниваем их с истинными значениями на тестовой выборке. В конспекте рассматриваются три метрики: MAE, MSE и RMSE.

MAE

Mean Absolute Error — средняя абсолютная ошибка.

MAE = (1 / n) · Σ |yᵢ − ŷᵢ|

Показывает средний размер ошибки без учёта её знака. Отдельные большие ошибки не получают дополнительного квадратичного штрафа.

MSE

Mean Squared Error — средняя квадратичная ошибка.

MSE = (1 / n) · Σ (yᵢ − ŷᵢ)²

Квадрат ошибки сильнее увеличивает вклад крупных промахов. Единицы измерения — квадрат единиц целевой переменной.

RMSE

Root Mean Squared Error — корень из MSE.

RMSE = √MSE

Измеряется в тех же единицах, что и целевая переменная, поэтому его часто удобнее интерпретировать.

Вычисление в Python:

from sklearn.metrics import mean_absolute_error, mean_squared_error

mae = mean_absolute_error(y_test, pred)
mse = mean_squared_error(y_test, pred)
rmse = np.sqrt(mse)
Какую метрику считать хорошей? Это зависит от задачи и масштаба целевой переменной. Например, ошибка в 10 единиц может быть большой для одной задачи и почти незаметной для другой. Поэтому метрики нужно интерпретировать в контексте данных и сравнивать с базовым уровнем.
На одном примере. Истинные продажи — 20 тыс., прогноз — 17 тыс. Тогда остаток = +3 тыс.; абсолютная ошибка = 3; квадратичная ошибка = 9. Усреднение таких ошибок по всем объектам даёт MAE и MSE, а корень из MSE — RMSE.

Практическое сравнение: MAE удобно объяснять как типичную абсолютную ошибку; RMSE сильнее реагирует на редкие крупные промахи. Обе метрики имеют единицы sales, а MSE — квадрат этих единиц. При сравнении моделей обязательно используем одну и ту же тестовую выборку.

Диагностика модели

6. Остатки (Residuals)

Остаток — разность между истинным значением и предсказанием модели:

eᵢ = yᵢ − ŷᵢ

Остатки помогают понять, как именно модель ошибается. Две модели могут иметь похожую метрику, но совершенно разную структуру ошибок.

Важное различие: остаток обычно считают как y_true - y_pred. Если поменять порядок вычитания, знак изменится, хотя абсолютная ошибка останется той же.

В примере с тестовой выборкой:

residuals = y_test - pred

Если e > 0, модель недооценила продажу; если e < 0 — переоценила. Важно смотреть не только на средний остаток: положительные и отрицательные ошибки могут взаимно компенсироваться.

Графический анализ

7. Диагностика: что говорят остатки

В рукописном конспекте важная мысль: одного числа MAE или RMSE мало. На графиках можно заметить закономерности, которые агрегированная метрика скрывает. Ниже схематичные иллюстрации, а не результаты обучения на реальном датасете.

7.1. Графики остатков: четыре типичных картины

Хороший ориентир

Точки разбросаны вокруг нуля без очевидной формы. Это не доказательство идеальной модели, но явных проблем на этом графике не видно.

Признак нелинейной связи

Ошибки зависят от значения прогноза: прямой может не хватать, чтобы уловить зависимость. Стоит проверить форму связи и признаки.

Неодинаковый разброс ошибок

По мере роста прогноза увеличивается разброс остатков (гетероскедастичность). Ошибки в разных диапазонах имеют разный масштаб.

Аномальное наблюдение

Большая ошибка одного объекта может ощутимо изменить MSE и RMSE. Проверь объект, а не удаляй его автоматически.

В частности, систематическая дуга на графике остатков подсказывает, что линейная модель не до конца описывает зависимость. В конспекте также отмечается: структуру остатков следует рассматривать относительно предсказаний или истинных значений и сравнивать с линией нуля.

Как построить график для своих данных

import matplotlib.pyplot as plt
import seaborn as sns

residuals = y_test - pred
sns.scatterplot(x=pred, y=residuals)
plt.axhline(0, color="red", linestyle="--")
plt.xlabel("Предсказанные продажи, ŷ")
plt.ylabel("Остатки (y − ŷ)")
plt.title("Остатки против предсказаний")
plt.show()

7.2. Распределение остатков

Гистограмма показывает, где сосредоточены ошибки, есть ли смещение, асимметрия и тяжёлые хвосты. В лекции ориентир — распределение примерно вокруг нуля. Но нормальность остатков не обязательна для самого построения прогноза; она особенно важна для некоторых статистических выводов и интервалов в классической модели.

sns.displot(residuals, bins=25, kde=True)
plt.xlabel("Остаток (y − ŷ)")
plt.show()

7.3. Normal Probability Plot (Q–Q plot)

Q–Q plot сравнивает квантили наблюдаемых остатков с теоретическими квантилями нормального распределения. Если точки приблизительно лежат на прямой, нормальное распределение является правдоподобным приближением. Если график заметно изгибается или его концы расходятся с прямой, распределение может отличаться от нормального.

from scipy import stats

fig, ax = plt.subplots(figsize=(6, 6))
stats.probplot(residuals, dist="norm", plot=ax)
ax.set_title("Q–Q plot остатков")
plt.show()
Как читать три графика вместе: scatterplot ищет структуру ошибки, гистограмма показывает её форму, Q–Q plot детальнее проверяет соответствие нормальному распределению. Нормальность сама по себе не гарантирует ни хорошего прогноза, ни корректности всех предположений модели.

7.4. Квартет Энскомба — почему графики обязательны

Квартет Энскомба состоит из четырёх наборов точек с почти одинаковыми средними, дисперсиями, корреляцией и линейной регрессией. Но их геометрия принципиально отличается. Поэтому метрики и коэффициенты без графика могут вводить в заблуждение.

Что объединяет 4 набора? Для каждого среднее x ≈ 9, среднее y ≈ 7.5, коэффициент корреляции r ≈ 0.816, а линия регрессии близка к ŷ = 3 + 0.5x. Тем не менее доверять одной прямой для всех четырёх картинок было бы ошибкой.

Готовая диагностика на своём датасете

# Остатки после model.fit(X_train, y_train) и model.predict(X_test)
residuals = y_test - pred

fig, axes = plt.subplots(1, 3, figsize=(15, 4))
sns.scatterplot(x=pred, y=residuals, ax=axes[0])
axes[0].axhline(0, color="red", linestyle="--")
axes[0].set(xlabel="Предсказания", ylabel="Остатки", title="Остатки")
sns.histplot(residuals, bins=25, kde=True, ax=axes[1])
axes[1].set(title="Распределение остатков")
stats.probplot(residuals, plot=axes[2])
axes[2].set_title("Q–Q plot")
plt.tight_layout()
plt.show()
После проверки

8. Повторное обучение на всех данных

Если качество на тестовой выборке устраивает, перед использованием модели её можно обучить заново на всех доступных данных.

final_model = LinearRegression()
final_model.fit(X, y)
После этого нельзя использовать метрику на тех же данных как честную оценку качества. Финальная модель уже видела все объекты, поэтому ошибка на них будет оценкой на обучающих данных, а не на независимой выборке.

Если качество на тесте не устраивает, можно вернуться к выбору модели или настройкам. В рамках следующей темы курса рассматривается регуляризация.

Логика такая: сначала оцениваем качество на отложенном тесте, принимаем решение о подходящем подходе и лишь потом переобучаем выбранную конфигурацию на всех доступных строках. Если неоднократно подбирать модель по тестовой метрике, тест перестаёт быть действительно независимой проверкой; для выбора гиперпараметров стоит использовать валидацию или кросс-валидацию.

Интерпретация

9. Коэффициенты модели

У линейной регрессии есть коэффициенты при признаках. В Scikit-learn их можно получить через атрибут .coef_.

final_model.coef_

coefficients = pd.DataFrame(
    final_model.coef_,
    index=X.columns,
    columns=["Coefficient"]
)

В примере признаки идут в порядке TV, radio, newspaper. По смыслу коэффициент показывает, как меняется прогноз при увеличении соответствующего признака на одну единицу, если остальные признаки зафиксированы.

ПризнакКоэффициент для иллюстрации (примерно)Интерпретация
TV+0.045При увеличении бюджета на TV на $1000 прогноз продаж увеличивается примерно на 0.045 тыс. единиц, то есть на 45 единиц.
Radio+0.188При увеличении бюджета на радио на $1000 прогноз увеличивается примерно на 0.188 тыс. единиц, то есть на 188 единиц.
Newspaper−0.001Коэффициент близок к нулю и в этой модели имеет небольшой отрицательный знак.
Осторожно с интерпретацией: коэффициент описывает связь внутри построенной модели при фиксированных остальных признаках. Его не следует автоматически трактовать как доказательство причинно-следственного эффекта.

Масштаб признаков

В этом примере все рекламные бюджеты измеряются в одинаковых единицах — тысячах долларов. В других задачах признаки могут иметь разные масштабы (например, площадь дома и число спален). Тогда для сопоставления масштабов может быть полезна нормализация или стандартизация. Это отдельная тема, которая в лекции только упоминается.

Свободный член модели доступен через final_model.intercept_. Он задаёт предсказание при нулевых значениях всех рекламных расходов (математически, хотя практический смысл такого сценария нужно оценивать отдельно).

print("Свободный член:", final_model.intercept_)
print(pd.Series(final_model.coef_, index=X.columns))
Практическое применение

10. Предсказание для новых данных

Для нового объекта нужно передать модели признаки в том же составе и порядке, что использовались при обучении.

Пример для иллюстрации: новая рекламная кампания — TV: 149, radio: 22, newspaper: 12 (тыс. долларов).

campaign = pd.DataFrame(
    [[149, 22, 12]],
    columns=X.columns
)

prediction = final_model.predict(campaign)
Почему DataFrame? При обучении модель получила таблицу с именами колонок. Передача DataFrame с теми же именами помогает сохранить соответствие признаков и избежать предупреждения о несовпадении формата входных данных.

Точность отдельного прогноза заранее неизвестна. Ориентироваться можно на результаты оценки модели на тестовой выборке, но это не гарантирует точность каждого конкретного предсказания.

Практика

11. Полный рабочий пример — от CSV до проверки

Ниже все основные команды собраны в одном месте. Это самостоятельное дополнение к рукописным записям, чтобы не приходилось искать импорты и переменные по всему конспекту.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error
from joblib import dump, load

# 1. Чтение данных. CSV должен содержать TV, radio, newspaper, sales.
df = pd.read_csv("Advertising.csv")
features = ["TV", "radio", "newspaper"]
X = df[features]
y = df["sales"]

# 2. Разделение
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

# 3. Обучение и прогноз
model = LinearRegression()
model.fit(X_train, y_train)
pred = model.predict(X_test)

# 4. Качество
mae = mean_absolute_error(y_test, pred)
mse = mean_squared_error(y_test, pred)
rmse = np.sqrt(mse)
print(f"MAE: {mae:.3f}, MSE: {mse:.3f}, RMSE: {rmse:.3f}")

# 5. Диагностика остатков
residuals = y_test - pred
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
sns.scatterplot(x=pred, y=residuals, ax=axes[0])
axes[0].axhline(0, color="red", linestyle="--")
axes[0].set(xlabel="Предсказания", ylabel="Остатки")
sns.histplot(residuals, bins=25, kde=True, ax=axes[1])
stats.probplot(residuals, plot=axes[2])
plt.tight_layout()
plt.show()

# 6. После оценки обучаем финальную модель на всех данных
final_model = LinearRegression()
final_model.fit(X, y)
print(pd.Series(final_model.coef_, index=features))

# 7. Прогноз на новую кампанию
campaign = pd.DataFrame([[149, 22, 12]], columns=features)
print("Прогноз продаж:", final_model.predict(campaign)[0])

# 8. Сохранение модели
dump(final_model, "sales_model.joblib")
restored_model = load("sales_model.joblib")
Важное условие: значения метрик и коэффициентов зависят от версии и содержимого CSV, выбора train/test и точной постановки задачи. Код специально не подставляет невычисленные результаты.
Сохранение модели

12. Сохранение и загрузка

Обученную модель можно сохранить на диск и затем загрузить, чтобы не обучать её заново при каждом запуске программы. В примере используется joblib.

from joblib import dump, load

# Сохранение
dump(final_model, "sales_model.joblib")

# Загрузка
loaded_model = load("sales_model.joblib")

# Использование загруженной модели
loaded_model.predict(campaign)
Важно: загружайте pickle/joblib-файлы только из доверенных источников. Такие файлы могут выполнять код при десериализации.

Краткий итог

  • Разделяем данные на train и test до обучения.
  • Обучаем модель через .fit(), получаем прогноз через .predict().
  • Считаем MAE, MSE и RMSE на тестовой выборке.
  • Изучаем остатки, чтобы увидеть структуру ошибок, а не только одно число метрики.
  • Если качество устраивает, обучаем финальную модель на всех данных.
  • Изучаем коэффициенты, делаем прогнозы для новых объектов и сохраняем модель.
